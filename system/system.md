# System

This explains the system.  The system has events.  The events have sources.  Events relate to the state of resources and obligations.
Sources provide documentation usually in the form of a document.

The state of those resources and obligations are changed by events.  

Aggregate information about state and changes in state are report reported to regulators per a reporting framework.

Events are recorded in an events journal.  Every event has a source.

[reporting-framework](../reporting-framework/framework.md)

The general journal is a projection of the events journal.

The general ledger is a projection of the general journal.

The primary financial statements are a projection of the general ledger.
